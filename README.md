# 纸靶调弓推演台 · Bow Paper-Tune Lab

给射箭器材店在客户上手拧弓之前，先在屏幕上把“出箭那一瞬间”看明白的浏览器系统。
TypeScript + three.js + IndexedDB，纯前端、无需后端。弓箭档案、调试记录、导入照片全部存在本机浏览器。

> 六个页面：**弓箭档案 · 配箭计算 · 出箭推演 · 纸靶诊断 · 调试记录 · 设置自检**。

## 运行

```bash
npm install
npm run dev        # http://127.0.0.1:5173 （占用时自动换端口）
npm run build      # tsc 类型检查 + vite 生产打包到 dist/
npm run preview    # 预览生产包
npm test           # vitest 物理/方向不变量测试
```

需要支持 WebGL2 的现代桌面/手机浏览器。首次打开会自动写入内置演示数据
（6 把常见磅数反曲/复合弓、7 种 spine 的箭、4 张带透视与光照不均的合成纸靶照片、
李先生的 5 步调试过程）。“设置”页可一键恢复这批演示数据。

## 功能与需求对应

1. **弓箭档案**：反曲 / 复合分类建档，拉力、拉距、弓长、弦距；复合记录偏心轮型号与让力比，
   反曲记录可换弓片型号 / 等级 / 片标磅数，更换后**拉力-拉距曲线 DFC 与储能即时改变**。
2. **配箭计算**：录入静态 spine、长度、GPI、箭头 / 插销 / 箭尾 / 箭羽 / 缠绕重量，
   自动算总重、重心、**FOC**、由 ATA spine 反推 **EI**、梁一阶 / 二阶频率、**动态 spine**，
   与弓的磅数 / 拉距需求对照给出偏软 / 匹配 / 偏硬；附“本弓 × 全部箭”适配表与箭头 what-if。
3. **出箭推演**：箭杆按细长 Euler-Bernoulli 梁处理，自由-自由振型 φ₁/φ₂ 烘焙成 DataTexture，
   在**顶点着色器里按振型叠加**弯曲（不逐帧换模型）。指撒反曲左右蛇形（射手悖论）幅度大，
   撒放器复合以上下抖为主。
4. **箭羽与擦碰检测**：羽片按偏置 + 螺旋角得到稳定转速慢慢旋转；对时间固定步长采样羽尖，
   检测离弦瞬间与**箭台刀片 / 弹性柱 / 弓窗**的接触，红色标记每帧锚定到弯曲 + 旋转后的羽上，
   并给出时刻与侵入量。
5. **高速摄影**：默认 **1000× 慢放**，时间轴按相机帧率逐帧（可 240 / 1000 / 4000 fps），
   支持上一帧 / 下一帧、归零、跳到穿纸；按曝光时间在窗口内多点采样出**运动拖影**；
   同一 renderer scissor 同步渲染**透视 + 顶视 + 侧视**三台机位。
6. **程序纸靶**：纸靶按射距摆放，过纸时依据当时 yaw / pitch 攻角与尾偏生成撕痕，
   Canvas 程序化绘制**锯齿毛边、纸纤维、中央焦孔与翻起纸片**，口子方向 / 长短与攻角一致；
   同 seed 永远生成同一张裂口，拖时间轴不会闪烁或重生成。
7. **纸靶诊断**：可导入客户实射照片（存 IndexedDB），在照片上点**箭头孔**与**箭羽撕痕**，
   按纸宽标定与射手 / 靶侧视角反算水平 / 垂直毫米偏差，和系统推演裂口**并排比较**，
   给出搭箭点、箭台中心距、弹性柱压力、箭头重量 / 换杆建议，并用统一“标准微调步数”
   **按改动量从小到大排序**。
8. **调试记录**：每次调整记一步（搭箭点 ±mm、箭头 ±gr 等自动生成变更描述），
   任选两步把纸靶口子用两色轮廓**叠加对比**，整条客户调试链可**从头回放**。
9. **18 / 30m 落点**：简化外弹道 + 种子化射手散布，裸杆（几乎不纠正初始攻角）与带羽箭
   （攻角按时间常数衰减）各射一组，在标准靶面上画弹着与组心，并给组径 / 平均半径。
10. **测试数据**：见 `src/core/sampleData.ts`、`samplePhotos.ts`、`seedSession.ts`。

## 三条硬指标（设置页有可视化自检，`npm test` 有同样断言）

- **方向与调弓手册一致**：同一把弓，箭头 **100gr → 125gr** 时 `spineRatio` 增大，
  纸靶撕痕在“有符号软侧坐标”上**单调朝偏软侧移动**（自检实测约 +1mm → +10mm）。
  右手弓偏软 = 尾左，左手弓自动镜像。
- **频率误差 < 3%**：ATA spine（28in 跨距、1.94 lbf 中点载荷）先用
  `EI = FL³/(48δ)` 反推，再用自由-自由梁
  `f₁=(β₁L)²/(2πL²)·√(EI/μ)`，`μ=总质量/全长`。推演直接以该 f₁ 驱动一阶振型，
  用过零插值“实测”频率与公式误差为 **0.00%**。
- **来回拖轴不抖**：`poseAt(cfg,t)` 是时间 `t` 的纯解析函数（解析脉冲响应 + 固定 seed），
  没有逐帧积分、没有随机重播种；乱序拖到同一帧结果逐字段一致。

### 读图约定（重要）

系统采用客户店内土办法的命名：**“口子上翘” = 搭箭点偏低 → 上调搭箭点**。
标准 paper-tune 图表常以“箭尾痕相对箭头孔”命名（tail-high / low），垂直方向词可能相反，
因此诊断结果同时给出物理毫米尾偏 `tailV/tailH`，并在设置页对照表中说明，避免观察侧 / 命名歧义。

## 目录

```
src/
  core/        纯物理与领域逻辑（physics/shot/diagnose/ballistics/selfcheck/种子数据）
  db/          IndexedDB 封装与首次播种
  state/       内存 store、记步 helper
  three/       LaunchScene：着色器振型、三机位、拖影、接触标记
  ui/          hyperscript DOM、tearDraw 纸靶绘制、targetFace 靶面
  pages/       六个页面
```

控制台暴露了 `window.__BOWTUNE__`（store、runSelfChecks、各物理函数），方便自动化核验。
